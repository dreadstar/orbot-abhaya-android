# Notes:
- UI-related functions (folder picker) should be moved to a dedicated UI module.
- Storage-related functions should be moved to storage manager modules.
- Scheduler logic and all job decomposition/assignment methods should be in a dedicated scheduler module/class.
- All model/data classes and enums should be split into logically grouped files in compute/model/.
- Interfaces should be placed in compute/network/ or compute/execution/ as appropriate.
- Any cross-module dependencies should be documented and handled via imports.
- All original functionality must be preserved; no methods omitted.
