## ✅ BEFORE WRITING ANY CODE FIX, ANSWER THESE QUESTIONS:

### 1. FILE STATE VERIFICATION
- [ ] Have I read the CURRENT STATE of ALL files I will modify?
- [ ] Have I documented what CURRENTLY EXISTS vs what I ASSUME exists?
- [ ] Have I checked for any discrepancies between plan and reality?

### 2. API TOUCHPOINT VERIFICATION
- [ ] Have I verified the ACTUAL SIGNATURE of EVERY method I will call?
- [ ] Have I checked parameter names, types, and nullability?
- [ ] Have I verified return types (callbacks vs direct returns)?
- [ ] Have I checked if methods are `suspend` functions vs regular functions?

### 3. DATA STRUCTURE VERIFICATION
- [ ] Have I verified ACTUAL property names (not assumed names)?
- [ ] Have I verified ACTUAL property types?
- [ ] Have I checked constructor requirements?
- [ ] Have I noted serialization annotations?

### 4. INTEGRATION VERIFICATION
- [ ] Have I found the ACTUAL location of every class/method I reference?
- [ ] Have I read its ACTUAL signature?
- [ ] Have I verified it EXISTS and is not deprecated?
- [ ] Have I checked for special requirements (coroutines, permissions)?

---

## 🛑 IF ANY ANSWER IS "NO", STOP IMMEDIATELY

**DO NOT WRITE CODE UNTIL VERIFICATION IS COMPLETE**

### Required Tools for Verification:
- `grep_search` - Find class/method/property definitions
- `read_file` - Read actual signatures and implementations
- `semantic_search` - Locate related code if grep fails
- `list_code_usages` - See how APIs are actually used elsewhere

---

## ⚠️ CONSEQUENCES OF SKIPPING VERIFICATION

- ❌ Compilation errors due to wrong signatures
- ❌ Type mismatches (File vs ByteArray, String vs InetAddress)
- ❌ Wrong parameter names (fileName vs path)
- ❌ Missing required parameters
- ❌ Calling non-existent methods
- ❌ Treating properties as methods or vice versa
- ❌ Wasted time on avoidable compile-fix cycles
- ❌ USER FRUSTRATION due to agent laziness

---

## ✅ CORRECT WORKFLOW

**WRONG:**
1. Read plan → 2. Write code → 3. Compile → 4. Fix errors → 5. Repeat

**RIGHT:**
1. Read plan → 2. **VERIFY ALL TOUCHPOINTS** → 3. Write validated code → 4. Compile successfully
